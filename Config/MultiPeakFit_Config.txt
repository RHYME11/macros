#######################################################################################
# MultiPeakFit complete 3-peak configuration example
# Blank lines and lines starting with # are ignored.
#
# This file is for multipeakfit(). PhotoPeakFit_Config.txt remains the single-peak
# example for photopeakfit().
#
# mode controls which GF3-style shape/background candidate is used:
#   auto      try allowed candidates and choose the best reduced chi-square.
#   highstat  use the full shared shape/background model.
#   lowstat   use Gaussian peaks plus linear background.
#
# rootFitOption is passed to ROOT hist->Fit(func, option).
# Default RQSN means:
#   R  use TF1 range.
#   Q  quiet ROOT fit output.
#   S  return TFitResultPtr for covariance.
#   N  do not store/draw fit automatically.
#
# option controls TSpectrum background removal before fitting:
#   none    do not subtract TSpectrum background.
#   global  estimate TSpectrum background over the full histogram.
#   local   estimate TSpectrum background over a local range.
#
# relativePosition:
#   false  fit each non-fixed P[i] independently.
#   true   use one PMASTER parameter:
#            P_i = PMASTER + (P0_i - P0_0)
#          If any fix P[i] is set, the first fixed P[i] anchors all positions.
#
# relativeFwhm:
#   false  fit each non-fixed W[i] independently.
#   true   use one WSCALE parameter:
#            W_i = WSCALE * W0_i
#          fix W[i] fixes only that peak width; other non-fixed widths use WSCALE.
#
# Global scalar parameters shared by all peaks:
#   A, B, C, R, BETA, STEP
#
# Per-peak indexed parameters:
#   P[i]  peak centroid/reference position
#   W[i]  peak FWHM/reference FWHM
#   H[i]  peak height
#
# Shared FWHM scale parameter:
#   WSCALE
#
# Position rule:
#   multipeakfit(h, low, high, {p0, p1, p2}, configFile)
#     uses peak positions from the function call; init P[i] does not override them.
#   multipeakfit(h, low, high, configFile)
#     requires contiguous init P[0], init P[1], ... values below.
#####################################################################################
